ALPINE WEATHER V38 — INCERTEZZA LUNGO IL PERCORSO GPX

V38 aggiunge il confronto ECMWF IFS / NOAA GFS / DWD ICON direttamente sul percorso GPX.

- campionamento configurabile del percorso (6/8/10 punti)
- usa l'orario stimato di passaggio di ciascun punto
- confronta temperatura, vento, raffiche o pressione
- mostra valori per modello, min/max e dispersione
- evidenzia il punto con maggiore dispersione
- nessun punteggio, ranking o interpretazione automatica del rischio
- distingue sempre il disaccordo tra modelli dalla probabilità di errore

Nota: il confronto è una verifica modellistica indicativa; non sostituisce bollettini ufficiali, osservazioni locali o valutazioni sul terreno.
