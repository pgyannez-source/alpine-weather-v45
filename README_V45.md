# Alpine Weather V45 — One Click

V45 aggiunge un avvio semplificato per Windows mantenendo il backend unificato di V44.

## Avvio
1. Installa Node.js 18+ se non presente.
2. Doppio clic su `AVVIA_ALPINE_WEATHER.bat`.

Lo script controlla Node.js, installa le dipendenze se `node_modules` manca, avvia il server e apre http://localhost:8787.

## Avvio manuale
`npm install`
`npm start`

## Arresto
Chiudi la finestra del server oppure premi CTRL+C.
